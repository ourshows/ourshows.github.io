# OurShow - Social Entertainment Platform

A comprehensive social entertainment platform merging movie/series discovery with community features, AI recommendations, and streaming options.

## Features

- 🎬 **Movie & Series Discovery** - Browse trending and top-rated content
- 🤖 **AI Vibe Search** - Find content based on your mood using Gemini AI
- 💬 **Community Chat** - Discuss with other movie lovers
- 📱 **Social Feed** - Share reviews and thoughts
- 📊 **Stats & Gamification** - Track your viewing habits and earn badges
- 🔥 **Watch & Download** - Access streaming links and download the mobile app

## Tech Stack

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Firebase (Authentication, Firestore)
- **APIs**: TMDB API, Google Gemini AI
- **Design**: Glassmorphism, Mobile-First Responsive

## Live Demo

🌐 **[Visit OurShow](https://yourshow.github.io/ourshow)** (Update after deployment)

## Local Development

1. Clone the repository
2. Open `index.html` in your browser or use a local server:
   ```bash
   npx http-server . -p 8080
   ```
3. Visit `http://localhost:8080`

## Configuration

Update `config.js` with your API keys:
- TMDB API Key
- Gemini API Key
- Firebase Configuration
